# Shadow Blade: Sideview Trials

A complete **2D side-view ninja platformer** focused on passing levels.

## Features
- 3 progression levels with gates, hazards, and enemy patrols.
- Platforming movement with gravity, jump, air-control, and **wall jump / wall slide**.
- Ninja combat and abilities:
  - Shuriken Burst
  - Dash Slash
  - Smoke Phase
  - Grapple Pull
- Level completion flow: clear enemies, open gate, advance to next stage.

## Play
Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then go to `http://localhost:8080`.
